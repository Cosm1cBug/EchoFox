## Implemented in this working tree

- **Configuration:** all 15 formerly dropped sections survive normalization; canonical/legacy precedence works per field, including nested providers. Invalid canonical values stay invalid rather than becoming defaults. Schema-resolved compact/snake-case environment aliases retain typed strings, parse JSON containers, give leaf overrides precedence and reject unknown/conflicting/prototype paths. External `ECHOFOX_CONFIG`, executable CLI and credential-presence-only config validation do not start a bot or write configuration into package source.
- **Privacy:** all four store adapters share content read/write policy, including edit writes, body/cache reads, SQLite lists, AI turns and excluded-chat timeline events. Edit events apply it before body processing. Zero memory retains/retrieves no AI turns but does not drop the current admitted prompt. Allowed SQLite edits also refresh the hot cache. Historical data is hidden, **not purged**; other metadata/retention/export paths remain under review.
- **AI/tool permissions:** execution and advertisement use the same enabled/whitelist/key/strict-argument/actor/chat restrictions. Global blocklist/newsletter tools require configured admins; chat tools cannot cross the originating chat even for an admin session. Tool handlers propagate failure instead of wrapping a denied fetch as success. SQLite message-tool access uses the adapter's actual list API.
- **Egress/HTTP:** canonical IP/DNS checks reject non-public/mixed/empty/error answers and pin validated addresses to the actual connection while preserving TLS hostname verification. Default redirects are off; allowed MediaFire hops are individually checked and HTTPS downgrade denied. AI URL fetch, RSS, MediaFire and image downloads use this boundary. Unverifiable configured public-fetch proxies fail closed. Seven AI tools and Telegram now await the actual Axios response API; offline tests check request serialization.
- **Consent/quota/spend:** fallback and all paid commands share policy, persisted attempt admission and serialized **single-process** budget reservations. Explicit opt-out wins over mentions/commands; private mode rejects non-admin fallback. Input/result/tool-round limits bound estimates. Unknown token/image prices deny instead of borrowing a cheap fallback; returned model names are accounted for and unexpected unpriced models latch a fault. Missing/uncertain billing retains labeled estimates; failed ledger writes block new paid admission. Images record raw cost before delivery. Redis usage writes use one atomic Lua operation and malformed totals fail closed; live Redis execution remains unverified.
- **Credential/log defenses:** always-on recursive structured/string/error/URL redaction includes Pino child bindings and the file-rotator fallback. External crash notifications carry a UUID correlation reference, not raw bodies/errors/stacks; Telegram text is sanitized too. Non-interactive logging now keeps genuine events/error type/code/frames as JSON without a background pretty worker; interactive development terminals retain pretty output. New session/config/secret/backup paths are excluded from Git, Docker contexts and npm artifacts. Fresh image session directories have private permissions; existing volumes/custom paths were not migrated.
- **Dashboard:** enabled instances require credentials; only failed auth consumes bounded IP budgets, so successful polling is not double-counted/rate-limited. Mutations require an intentional header and reject cross-origin browser requests; frontend supplies it. Host/trust-proxy/failure-window settings are explicit. Background builds are opt-in; a completed build replaces maintenance routing without restart.
- **Monitoring:** child exit/signal status informs health, configured health port is respected and existing `NODE_OPTIONS` survive. Prometheus Basic auth is job-level with a mounted password file, not fake environment interpolation/static-config nesting. Grafana uses a separate file secret with no default password; host port 3002 avoids the dashboard collision. Compose preserves legacy pairing mounts and adds `/app/data` persistence. No restart/backoff/shutdown policy change.
- **Verification/release/artifacts:** production audits distinguish findings from registry/parse/process failure. Pre-push scans actual outgoing ref spans, full changed blobs (including merge/binary cases), annotated push-object messages and tracked/untracked working content without printing matched secrets. CI/local frontend typechecking follows both project references via the declared `typecheck` script. Actions are SHA-pinned, Docker/npm/release publication has required quality/license gates, required builds/pack checks cannot fall back to fake success, version-history errors no longer invent `0.0.0`, registry absence is distinguished from lookup failure, and the actual npm archive is checked for CLI/frontend/build inputs plus runtime/credential content. Source archives retain locks and complete frontend configs. License inconsistency is a deliberate failing gate, not bypassed.
- **Delivery/dependencies:** RSS only records successful sends, leaving failures retryable. The newly observed legacy sticker-parser advisory has a narrow shared ASF/WMV/path/URL/size input guard in the command and media worker. The two moderate audit findings remain visible; no breaking downgrade or forced upgrade was applied.
